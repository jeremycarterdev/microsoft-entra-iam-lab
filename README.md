# Microsoft Entra ID IAM Lab

## Overview

This repository documents my hands-on experience with Microsoft Entra ID and Identity and Access Management (IAM).

The lab is designed around realistic identity administration and security scenarios, including user lifecycle management, authentication, access control, identity monitoring, and privileged access.

Rather than only studying IAM concepts, I use this environment to configure, troubleshoot, investigate, and document identity-related scenarios in Microsoft Entra.

## Technologies

- Microsoft Entra ID
- Microsoft Azure
- Microsoft 365
- Microsoft Graph
- PowerShell

## IAM Skills

This lab will document hands-on work involving:

- User and group administration
- Role-Based Access Control (RBAC)
- Least privilege
- Multi-Factor Authentication (MFA)
- Authentication methods
- Sign-in and audit logs
- Conditional Access
- Joiner-Mover-Leaver identity lifecycle
- Privileged Identity Management (PIM)
- Identity Governance
- Enterprise applications and Single Sign-On (SSO)
- Microsoft Graph and PowerShell automation

## Lab Projects

Projects and investigation scenarios will be added as they are completed and documented.

## Purpose

My goal is to build practical experience administering and securing identities in Microsoft cloud environments while developing the skills required for Identity and Access Management and cloud security roles.
